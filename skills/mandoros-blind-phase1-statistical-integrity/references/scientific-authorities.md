# Scientific authority routing

Use the trial report first. Use these authorities to define extraction fields
and statistical distinctions, never to fill a value absent from the paper.

- **CONSORT 2025:** outcome definition must preserve variable, analysis metric,
  aggregation method and timepoint; extract who was analyzed in each group,
  missing-data handling, and statistical methods for benefits and harms.
  https://www.bmj.com/content/389/bmj-2024-081123
- **Cochrane Handbook, Chapter 5:** collect design, participants, interventions,
  outcomes, arm-level sample sizes/results, between-group effects, precision,
  timepoints, subgroups, adverse outcomes, and the exact methods/covariates used.
  https://www.cochrane.org/authors/handbooks-and-manuals/handbook/current/chapter-05
- **ICH E9:** preserve hypotheses/estimands, model, confidence intervals,
  sidedness, baseline adjustment, analysis sets, missing-data handling and
  multiplicity as reported.
  https://www.ema.europa.eu/en/scientific-guidelines/ich-e9-statistical-principles-clinical-trials
- **ICH E9(R1):** distinguish estimand, estimator and estimate; when reported,
  retain population, treatment conditions, endpoint/variable, intercurrent-
  event strategy and population-level summary.
  https://database.ich.org/sites/default/files/E9-R1_Step4_Guideline_2019_1203.pdf
- **FDA Multiple Endpoints (2022):** preserve endpoint ordering, hierarchy and
  multiplicity adjustment; never infer a formal p-value after a testing gate
  has failed.
  https://www.fda.gov/regulatory-information/search-fda-guidance-documents/multiple-endpoints-clinical-trials
